# 桌面歌词就近操作与样式自定义设计

日期：2026-09-29。目标分支：`feat/overlay-quick-controls`；仅本地提交，不推送。仓库无 `origin`，以本地 `main` 新建分支并快进至已完成的桌面歌词版本。

## 目标与边界

用户不想每次移动鼠标到顶部音符菜单。歌词旁直接提供常用操作，并可调整浮层背景透明度、歌词文字颜色和文字背底颜色。保持目前只读网易云播放状态、Rust 歌词引擎及 JSON 行协议不变；本次不加入上一曲、暂停、下一曲等播放器控制。

## 交互

- 歌词浮层右上方跟随一条独立的悬浮工具条，默认展开，四个操作依次为拖动手柄、位置锁定/解锁、样式设置、收起工具条。收起只将工具条变为一个可展开的小按钮，不隐藏歌词。收起状态保存在本机。工具条始终可点；锁定只使歌词浮层点击穿透，并禁用拖动手柄。解锁后既可拖手柄，也可像现在一样拖动歌词浮层。
- 工具条不是歌词 NSPanel 的子控件，而是独立 NSPanel：`ignoresMouseEvents` 不会随歌词锁定而应用到工具条。歌词移动、显示/隐藏、多显示器切换时更新工具条位置；优先放在歌词上方，空间不够时置于下方，限制在当前屏幕可见范围内。隐藏歌词时工具条也隐藏，菜单栏保留显示/隐藏、锁定、设置、辅助功能和退出的兜底入口。
- 点击样式按钮打开原生小设置窗；再次点击可关闭。设置窗显示三个颜色选项：浮层背景、歌词文字、文字背底；两个显式不透明度滑块：浮层背景、文字背底（0–100%，0% 为完全透明）。原生颜色面板选色，滑块和颜色更改立即作用于歌词。文字背底默认透明，采用紧贴当前句和副句文字宽度的圆角底片，而非遮满整行。设置窗有“恢复默认”以避免颜色组合使文字不可读。
- 默认视觉保持现状：背景约 `#131313` / 91% 不透明，文字白色（副句使用同色的 70% 不透明度），文字背底黑色 / 0% 不透明。颜色用不含个人音乐资料的十六进制 RGB 字符串、透明度用限定在 0–1 的数值存入 App `UserDefaults`；缺失或损坏的值回退默认值。状态、加载、错误消息使用相同样式。
- 图标按钮提供中文辅助功能标签和提示；原生设置控件可通过键盘导航，滑块旁有数值标签。任何样式/工具条操作都不触发歌词查询或网易云操作。

## 结构与验证

- `OverlayStyle.swift` 负责颜色转换、数值校验和持久化；`ToolbarPlacement.swift` 负责屏幕安全位置计算；`LyricsView.swift` 负责可变颜色与紧贴文本的背底。`OverlayControls.swift`/`StyleSettingsWindow.swift` 分别负责两种 UI；`main.swift` 仅协调浮层、工具条、设置窗与既有 Rust 行流。
- 在合成偏好数据上测试默认值、读写回环、非法色值/透明度和边界位置；构建时 Swift 编译、Rust 测试保持通过。用独立的预览包检查工具条、透明度、锁定点击穿透、跨位置跟随、收起/展开和重启持久化，再替换正式 `dist/网易云桌面歌词.app`。
- 本机 App 使用 ad-hoc 签名；正式包更新后辅助功能既有授权可能失效。预览包不能代替正式包授权验证；不自动更改系统安全设置。发布时先保留原包，最后构建正式包，提醒用户必要时在系统设置重新添加 App 并重启。
