# macOS 网易云桌面歌词 MVP 设计

日期：2026-09-29。目标分支：`feat/macos-lyrics-usable`（由本地 `main` 建立，无远端，只本地提交）。

## 已验证前提

网易云 3.1.12 / macOS 26.6.2 的当前只读 CLI 已在本机取得歌曲 ID、原始位置，使用辅助功能菜单区分播放/暂停，长暂停冻结（自动测试 51 项通过）；本机未授权以外的读失败均诊断，不猜播。实际当前曲目用数字 ID 请求 `https://music.163.com/api/song/lyric?id=…&lv=-1&tv=-1` 返回 HTTP 200，包含 `lrc.lyric` / `tlyric.lyric`，不需 Cookie。网易云接口和客户端内部文件/菜单均未公开稳定保证，必须显式降级；本地终端或正式 App 须有辅助功能权限。

## 产品方案与取舍

1. **推荐：Rust 核心 + 极薄 Swift/AppKit 桌面外壳。** 歌词请求、解析、缓存、同步、源探针、JSON 行协议由 Rust 完成；Swift 仅建立 NSPanel、菜单栏控制、读 stdout 并渲染。Rust AppKit/Objective-C 手动 FFI 可做到但窗口和事件循环更易引入 UB；Swift 是系统 UI 桥，不承载业务逻辑。构建后提供可双击的 `.app`，以及从已授权终端运行的脚本模式。只用本地构建工具，不设置或推送远端。
2. **备用：纯 Rust 命令行歌词**，网络或 UI 权限失败时仍可独立诊断；不把它当桌面歌词最终交付。
3. **暂不选：私有 MediaRemote、注入网易云、账户 Cookie、控制中心截图、播放控制。** 维护和权限代价与首版不匹配。

## Rust 核心

- `lyrics.rs`：只对非空十进制歌曲 ID 发 HTTPS GET，`/usr/bin/curl` 子进程设置连接 3 秒、总 8 秒、HTTPS 限制，不跟随非 HTTPS 重定向；响应上限 256 KiB，JSON code 校验，`lrc.lyric` 和可选 `tlyric.lyric`；无歌词/纯音乐、网络失败、解析失败分开。每个曲目内存缓存；网络故障 10 秒后允许一次重试；不存 cookie、播放记录或歌词到磁盘。
- `lrc.rs`：支持 `[mm:ss]`、1–3 位小数、多时间标签、`[offset:+/-ms]`、重复及乱序标签；原文和翻译按时间戳（容差 250 ms）配对。忽略元信息/无时间行，二分查找当前行。严格上限保护病态歌词；不输出/测试真实歌曲内容。
- `lyrics_stream.rs`：组合现有 `sample`（AX + LevelDB + `PlaybackTracker`）和网络缓存；`--lyrics-json` 每采样输出一行 JSON：`kind=loading|line|unavailable`、当前原文/译文/下一句、播放标记、相对位置或简短诊断。先输出 loading 才发请求；切歌清旧歌词；暂停保持当前行；状态丢失清屏；标准输出 flush，进程退出清内存。普通 `cargo run` CLI 的原输出不变。JSON 不包含曲目 ID、用户信息或原始日志。

## AppKit 外壳

- 桌面浮层 760×112 pt，底部居中，深色半透明圆角，当前句约 24 pt 白色粗体，译文或下一句 15 pt 灰白，细小朱红色进度提示。对大屏留边，置顶并出现在全空间/全屏辅助层；状态行仅用于无歌/权限/网络错误，加载不显示旧歌词。使用系统字体和原生窗口，无图标资源依赖。
- 菜单栏入口：显示/隐藏、锁定/解锁（锁定时点击穿透；解锁可拖动窗体）、打开辅助功能设置（只导航，不替用户更改权限）、退出；默认可拖动，用户确认位置后锁定。窗口位置与显示/锁定偏好只由 AppKit 用户设置保存，不保存音乐资料。
- App 可独立从 Finder 启动（从 Resources 启动 Rust bridge）或由 `scripts/run-desktop.sh` 从终端用 stdin pipe 启动，以复用终端现有辅助功能授权。App 启动失败仍展示明确状态而非空窗；退出时终止子进程。

## 验收与限制

- 测试：合成 LRC 边界、翻译对齐、接口 JSON 分类与 ID 校验、切歌/暂停/恢复/异常行协议、构建脚本基本检查；`cargo test`、fmt、clippy、`swiftc` 构建通过；编译 `.app`。
- 实机：播放出歌词；暂停超过 8 秒保持同一句；恢复继续；下一首清旧歌词并换新；按 UI 操作前/后拖动后同步；退出探针及权限错误显示状态。能用截图对比窗口位置与文本，不能把所有真实歌曲内容提交 Git。
- 首版仅本机 macOS / 网易云版本；需联网获取歌词，网络失败显示错误；关闭终端脚本会结束浮层；某些歌曲无逐行歌词只显示明确状态；不存在的歌词不自动补第三方源。不会自动安装权限、不会进入 App Store，也不承诺高精度卡拉 OK 字级滚动。
