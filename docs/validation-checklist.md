# 网易云音乐 3.1.12 播放状态现场验收

日期：2026-09-29。设备：Apple Silicon / macOS 26.6.2。本项目只读，不自动操作网易云客户端；播放内容、账号信息和原始日志不要写进 Git。

命令：

```bash
cargo run -- --samples 120 --interval-ms 500
```

逐项在网易云客户端**手动**操作，对照输出 `track`、`raw_ms`、`estimated_ms`、`playing`，记录可观察到的切换延迟。无需提交真实歌曲标识；可将不同歌曲记为 A、B。

| 操作 | 合格标准 | 本次结果 / 观察延迟 |
| --- | --- | --- |
| 客户端未启动 | `NotRunning`；不沿用上次歌曲 | 待人工验证 |
| 启动但尚未播放 | 不把上次歌误认为当前播放；如有历史快照则标记限制 | 待人工验证 |
| 开始播放 | `track` 对应实际歌曲，原始进度随播放刷新 | 待人工验证 |
| 切歌、上一首、下一首 | ID 与实际歌曲对应，估算进度重置；记录切换延迟 | 待人工验证 |
| 播放 → 暂停 → 恢复 | `playing` 正确切换；暂停时估算进度冻结 | 待人工验证 |
| 播放中向前、向后拖动 | 原始进度可观测；向后跳转经第二个递进样本确认 | 待人工验证 |
| 暂停时拖动 | 原始位置变化；估算位置随新样本校正 | 待人工验证 |
| 退出客户端 | `NotRunning`，旧快照不再输出 | 待人工验证 |
| 缺目录、空目录、坏记录、缺字段 | `MissingDirectory`、`NoSong`、`FormatChanged`、`MissingField` 分开报告 | 合成输入单元测试覆盖；实机不修改客户端数据 |
| 权限不足 | 输出 `PermissionDenied`，不提权、不改系统权限 | 临时目录权限单元测试覆盖；未改变网易云目录权限 |

## 已有验证

- 自动化：2026-09-29，`cargo test` **25 passed**（源解码、日志读取、进程发现、CoreAudio 结果合并、时间模型、CLI 参数、错误路径复位、空目录与权限分类）。
- 实机只读采样：客户端 3.1.12 运行时连续 4 次获得非空歌曲标识，`raw_ms` 随时间向前刷新，`playing=true`，估算位置跟随；只验证了**播放中**这一种状态，不据此宣称暂停、切歌、进度拖动已经可靠。
- 对日志格式的适配仅针对当前安装版本；App 升级后需重跑这张表。

**阶段结论：待人工验证。** 在上述真实交互全部验证前，不将本探针当成歌词同步的可靠数据源。若必要字段缺失或 CoreAudio 与暂停不一致，应判为**不可继续**，讨论 Accessibility 等备选；非关键限制可标明条件后判为**受限继续**；全项符合才能判为**可继续**。
